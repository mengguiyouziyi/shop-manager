## 🔧 开发环境配置

### 后端环境
```bash
cd backend-python
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### 前端环境
```bash
cd frontend
npm install
npm run dev
```

### 数据库环境
- MySQL 8.0+
- Redis (可选，用于缓存)

## 📝 代码质量标准

### 后端代码标准
- **命名规范**: 使用snake_case
- **文档注释**: 每个函数必须有docstring
- **错误处理**: 统一的错误响应格式
- **日志记录**: 关键操作必须记录日志
- **测试覆盖**: 核心功能必须有测试

### 前端代码标准
- **命名规范**: 组件使用PascalCase，文件使用kebab-case
- **类型安全**: 使用TypeScript，定义完整接口
- **状态管理**: 使用Pinia进行状态管理
- **响应式设计**: 支持不同屏幕尺寸
- **用户体验**: 加载状态、错误提示、成功反馈

## 🚨 常见问题与解决方案

### 问题1：前端页面空白
**解决方案：**
1. 检查路由配置是否正确
2. 验证组件是否正确导入
3. 检查控制台是否有错误
4. 确认API接口是否正常

### 问题2：后端API错误
**解决方案：**
1. 检查日志文件 `logs/app.log`
2. 验证数据库连接
3. 检查依赖包版本
4. 确认环境变量配置

### 问题3：数据验证失败
**解决方案：**
1. 检查Schema定义
2. 验证请求数据格式
3. 检查数据库约束
4. 确认字段类型匹配
