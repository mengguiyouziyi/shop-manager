# 店铺管理系统侧边栏菜单设计图

## 设计概述
基于现有Layout.vue组件，升级为Element Plus Menu组件，采用深蓝色主题的企业级设计风格。

## 颜色方案
- 主背景: `#1F2D3D` (深蓝色)
- 文字颜色: `#FFFFFF` (白色)
- 选中状态: `#409EFF` (Element Blue)
- 悬停状态: `rgba(64, 158, 255, 0.1)`
- 分组标题: `#8A97A8` (浅灰色)

## 功能特性
1. **多级菜单结构** - 支持二级菜单展开/折叠
2. **路由导航** - 点击菜单项跳转对应页面
3. **权限控制** - 根据用户角色显示对应菜单
4. **响应式设计** - 适配桌面和移动端
5. **折叠功能** - 支持侧边栏整体折叠

## 技术实现
- 使用 Element Plus `el-menu` 组件
- Vue 3 Composition API + TypeScript
- Pinia 状态管理
- Vue Router 路由集成

## 菜单数据结构
```typescript
interface MenuItem {
  path: string
  name: string
  icon: string
  children?: MenuItem[]
  permission?: string[]
}
```

## 响应式断点
- 桌面端: 侧边栏宽度 260px
- 平板端: 侧边栏宽度 200px  
- 移动端: 侧边栏隐藏，使用汉堡菜单
